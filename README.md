# Voice_Assistant
# 🎙️ Python Voice Assistant

A lightweight, personal desktop voice assistant built with Python. This script listens to microphone input, processes spoken commands using Google's Speech Recognition API, and responds using text-to-speech.

## ✨ Features

* **Conversational Greeting:** Greets you dynamically based on the time of day.
* **Wikipedia Summaries:** Ask it to search Wikipedia, and it will read the first two sentences of the result.
* **Web Navigation:** Command it to open Google or the YouTube homepage.
* **YouTube Search:** Say "search YouTube for [topic]" and it will automatically open the search results for that specific topic.
* **Time Check:** Ask for the current time.
* **Humor:** Ask it to tell you a joke using the `pyjokes` library.

## 🛠️ Prerequisites & Installation

This project uses Python 3. You will need to install a few external libraries for the speech recognition and text-to-speech engines to work.
